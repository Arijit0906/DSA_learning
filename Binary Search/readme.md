# Day 5 - DSA Journey 🚀

Today I focused on **Binary Search** and learned how it can be applied to rotated sorted arrays. These problems helped me understand how to identify the sorted half of an array and narrow down the search space efficiently.

## 📚 Topics Learned
- Binary Search
- Rotated Sorted Array
- Finding the sorted half
- Time Complexity: **O(log n)**

## ✅ Problems Solved

### 1. Find Minimum in Rotated Sorted Array
**What I learned:**
- How to find the pivot (minimum element) using binary search.
- Comparing the middle element with the right boundary to decide which half to search.
- Solving the problem without scanning the entire array.

**Difficulty:** Medium

---

### 2. Search in Rotated Sorted Array
**What I learned:**
- How to determine which half of the array is sorted.
- Applying binary search on the sorted half.
- Reducing the search space efficiently to achieve **O(log n)** time complexity.

**Difficulty:** Medium

---

## 💡 Key Takeaways
- Binary Search is not limited to sorted arrays; it can also solve many modified search problems.
- Identifying the sorted portion of a rotated array is the key to solving these questions.
- Understanding the search conditions is more important than memorizing the algorithm.
