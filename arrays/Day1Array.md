### Array Data Structure

An **Array** is a fundamental data structure that stores a fixed-size collection of elements of the same data type in contiguous memory locations.

### Key Concepts Learned

- Arrays store multiple values under a single variable name.
- Elements can be accessed using their index.
- Arrays provide fast element access with **O(1)** time complexity.
- Learned common array operations:
  - Traversal
  - Insertion
  - Deletion
  - Searching
  - Updating
