## Array
An array is a fundamental data structure in programming that stores a fixed-size, sequential collection of elements of the same data type under a single variable name
# Data Structures & Problem Solving

## 📚 What I Learned Today

Today, I learned about the **Array Data Structure**.

### Key Concepts Covered

* Arrays are used to store multiple elements of the same data type in contiguous memory locations.
* Elements can be accessed using their index.
* Arrays provide fast access to elements using indexing (`O(1)` time complexity).
* Common operations include:

  * Traversal
  * Insertion
  * Deletion
  * Searching
  * Updating elements
